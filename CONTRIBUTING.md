# Contributing to Ledger

Thank you for your interest in contributing! Here's how to get started.

## Development Setup

1. Fork and clone the repository
2. Follow the setup guide in [README.md](README.md)
3. Create a branch: `git checkout -b feature/your-feature`

## Making Changes

- Follow existing code style and naming conventions
- Add comments for complex business logic (especially insurance rules)
- Test your changes locally before submitting

## Pull Request Guidelines

- Keep PRs focused and small
- Write a clear description of what changed and why
- Reference any related issues

## Reporting Bugs

Open an issue with:
- Steps to reproduce
- Expected vs actual behavior
- Your environment (OS, Node.js version, Python version)

## Feature Requests

Open an issue with the `enhancement` label. Describe the use case and why it would benefit the project.
